# Cosmic Answer landing-page mockups

**Tracking:** AB#6167, AB#6170, and AB#6171  
**Decision:** Cosmic Answer is the selected default Project 42 direction  
**Status:** Owner-review mockups; not production assets  
**Created:** 2026-07-27

These three landing directions apply the selected Cosmic Answer identity without
changing the Project 42 product promise:

> Project 42 makes artificial intelligence understandable from your first
> question to your first reliable agent. Learn at your pace, check what you
> know, and keep a record of your progress.

## Options

### 01 — Cinematic split

[Open the full mockup](01-cinematic-split.png).

- Strongest immediate expression of “42” and the universal-answer idea.
- Clear Learn and Field Guide product split.
- Best for a visually dramatic public gateway.
- Production HTML must replace all rendered placeholder lines and labels.

### 02 — Editorial journey

[Open the full mockup](02-editorial-journey.png).

- Strongest beginner-to-advanced narrative.
- Best balance between cosmic wonder and an approachable learning product.
- Makes “first question” through “reliable agent” visible as a journey.
- The light lower section offers the broadest long-form readability.

### 03 — Learning universe

[Open the full mockup](03-learning-universe.png).

- Strongest view of learning paths, progress, and the open-source future.
- Best fit for returning learners and a product that feels substantial.
- Denser than the other directions and requires careful responsive reduction.
- Production should not expose learner-specific data on the signed-out gateway.

### 04 — Recommended hybrid

[Open the full mockup](04-recommended-hybrid.png).

- Uses the Editorial Journey structure and bright, readable learning section.
- Uses the stronger Cinematic Split 42/orbit hero.
- Keeps only non-personal learning-universe cues on the public page.
- Retains the approved promise, clear Learn and Field Guide entry points,
  mastery evidence, and a restrained open-source/self-hosted signal.
- This is the working production direction unless the owner requests revisions.

## Recommended synthesis

Use **02 — Editorial journey** as the public landing-page foundation, retain the
strong 42/orbit hero treatment from **01 — Cinematic split**, and reserve the
learning-universe/progress language from **03** for signed-in Learn dashboards.
This keeps the first-time story simple while giving the product room to become
deeper after sign-in. Mockup **04 — Recommended hybrid** records that synthesis.

## Production boundaries

- Treat these raster images as design evidence, not shippable page screenshots.
- Keep meaningful text, navigation, calls to action, progress, and product labels
  in semantic HTML.
- Reconstruct the mark and orbital system as canonical, original vector assets.
- Test contrast, keyboard access, zoom/reflow, screen readers, forced colors,
  reduced motion, touch targets, responsive crops, and image alternatives.
- Complete originality, trademark/conflict, and licensing review before release.
- Maintain separate readable labels for Learn and Field Guide; color alone is
  never the distinction.
- The public Project 42 deployment is a configured instance of the same
  open-source product. Only tenant identifiers, secrets, owner records, and
  private operational configuration stay outside the public distribution.

## Provenance

The mockups were generated on 2026-07-27 with OpenAI image generation using the
owner-selected Cosmic Answer exploration as visual reference. Prompts prohibited
provider logos, copyrighted characters, and *Hitchhiker's Guide* imagery. Text
visible inside the raster mockups is illustrative; approved production copy is
maintained separately and must be rendered as HTML.
