Safe Tool Use & Schema-Constrained Execution

When language models invoke tools, they produce structured JSON arguments matching a predefined function schema. In production environments, this execution boundary must be strictly sandboxed.

By decoupling tool discovery from execution privileges, we prevent untrusted prompt injections from acquiring unintended administrative access to underlying database records or host filesystems.

// Safe Tool Invocation with Deterministic Zod Schema Validation import { z } from "zod"; import { executeSandboxedTool } from "@project42/platform/tools"; const WeatherToolSchema = z.object({ location: z.string().min(2), units: z.enum(["metric", "imperial"]).default("metric") }); export async function handleToolCall(rawArgs: unknown) { const validatedArgs = WeatherToolSchema.parse(rawArgs); return await executeSandboxedTool("get_weather", validatedArgs); }
