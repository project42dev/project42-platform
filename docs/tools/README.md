## Category breakdown

**Coding agents in CLI** — run in your terminal, no IDE required:
Claude Code, Aider, Codex CLI, OpenCode, Gemini CLI

**Coding agents in VS Code** — VS Code extensions with agentic loops:
Cline, Kilo Code, Continue, Roo Code, GitHub Copilot

**Coding agents in an IDE** — standalone AI-first IDEs:
Cursor, Windsurf

**Cloud / autonomous agents** — run in the cloud, async task assignment:
Devin, Jules

**Orchestrators / personal-agent runtimes** — route tasks across agents and surfaces:
OpenClaw
