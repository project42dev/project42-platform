# Changelog

All notable changes to this deployment are recorded here. The releases page
renders this file: `npm run releases:generate` compiles it into
`config/release-notes.json`, and `npm run releases:check` fails when the two
have drifted.

The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and
released versions use semantic versioning. A heading must be `## [0.1.0]` or
`## [0.1.0] - 2026-01-31`; a release with no bullet points is skipped.
