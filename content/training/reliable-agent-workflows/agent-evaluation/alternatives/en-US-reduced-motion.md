# Evaluate Agent Behavior with Evidence: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## evaluation-contract

Present the complete contract as one static form.

Text alternative: Each case has a stable ID and slice plus versioned inputs, observable outcomes, permitted tools, prohibited behavior, scoring criteria, and resource limits.

## representative-and-adversarial-set

Show all case slices and coverage labels in a static matrix.

Text alternative: Four representative, two boundary, two adversarial, and two prior-failure cases cover important journeys and critical risks.

## score-outcome-and-trajectory

Display all rubric lanes and evidence sources simultaneously.

Text alternative: Deterministic checks, blinded human review, and calibrated model signals contribute separate evidence to a scored run.

## grader-demonstration

Show both scored run records side by side.

Text alternative: The polished run fails permission, approval, and retry checks. The bounded run requests clarification, preserves authority, and stops safely.

## compare-and-gate

Present the complete baseline-candidate table and gate results statically.

Text alternative: Candidate improvements are accepted only when must-not-regress safety and permission slices pass and practical improvement exceeds the declared threshold.

## continuous-evaluation

Show the entire governed intake sequence as a static flow.

Text alternative: Incident evidence is minimized, reviewed, versioned, added to the proper slice, and protected from holdout contamination.
