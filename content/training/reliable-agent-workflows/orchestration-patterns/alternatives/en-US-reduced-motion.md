# Choose Reliable Orchestration Patterns: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## simplest-sufficient-pattern

Show the entire decision funnel as a static list.

Text alternative: Questions ask whether one bounded operation works, whether ordered dependencies exist, whether input selects a branch, whether control transfers, whether branches are independent, and whether measurable revision is needed.

## manager-and-handoff

Display both ownership timelines at once.

Text alternative: The manager remains active while a specialist returns evidence. In a handoff, parent transfers control to security-specialist, which later returns control to parent before approval.

## parallelism-and-joins

Show start and finish timestamps in a static table.

Text alternative: Research, review, and validation start together and finish in different orders. Parent approval waits for successful current-revision evidence from all three IDs.
