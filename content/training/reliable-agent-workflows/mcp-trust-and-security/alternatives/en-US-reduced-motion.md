# Secure MCP Trust Boundaries: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## explicit-server-trust

Present the complete inventory as a static checklist.

Text alternative: Operator, provenance, transport, destination, actions, retention, updates, and incident contact are reviewed before connection.

## trust-demonstration

Show requested and approved permissions in static columns.

Text alternative: Search is project scoped, comment requires exact review, and delete and administrator access are rejected.

## content-remains-untrusted

Show content and authority lanes in one static diagram.

Text alternative: Results carry provenance and validation while credentials, policy, consent, and tool authority remain outside returned content.

## authorization-boundary

Present the validation sequence as a numbered static checklist.

Text alternative: Server identity, signature, issuer, expiry, audience, subject, resource, scopes, client, redirect, state, and consent must agree.

## least-privilege-approval

Display standing scope and one approval envelope side by side.

Text alternative: The approval shows server, client, tool, target, data, effect, and scope before execution.

## observe-drift-recover

Present the recovery branches as a static table.

Text alternative: Stop, revoke, preserve, assess, independently verify, and reapprove are shown in the recovery sequence.

## worked-boundary-map-lab-narration

Read the flow top to bottom as a static text diagram.

Text alternative: User consent reaches host policy; sanitized data reaches transport and server; independent state returns to the host data lane; model context cannot change authority.

## simulation-versus-live-integration-lab-narration

Present the comparison as a static two-column table.

Text alternative: The offline fixture has synthetic facts and no effects; live integration requires transport, cryptography, approvals, calls, storage, and observed state.
