# Defend a Portable, Secure, Reversible Model Service: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## mission-boundaries-narration

Display the contract and adapters simultaneously as a static table.

Text alternative: Artifact, endpoint, security, evaluation, capacity, telemetry, lifecycle, recovery, and approvals remain stable while environment commands differ.

## mission-demonstration

Present the three adapters side by side in a static mapping table.

Text alternative: All adapters preserve exact identity, access controls, evaluation, load, telemetry, rollback, incident recovery, and handoff evidence.

## build-protect-narration

Use static artifact and security control tables with explicit pass, fail, and quarantine labels.

Text alternative: Failed verification quarantines the build; prompt content never grants authority; secrets remain outside packages and evidence.

## evaluate-size-narration

Provide exact values and labeled static tables in addition to any charts.

Text alternative: Critical failures stay visible beside aggregate results; the capacity decision records distributions, saturation, rejection, warm-up, and stop conditions.

## observe-change-recover-narration

Present lifecycle and incident states as numbered static ledger entries.

Text alternative: Every state preserves exact identities, authority, evidence, affected work, postconditions, and residual risks without storing secrets.

## evidence-handoff-narration

Display artifacts, criteria, scores, evidence references, and handoff fields in static tables.

Text alternative: Every score cites immutable evidence; the handoff includes versions, owners, limits, alerts, rollback, recovery, risks, expiry, and next review.
