# Make Model Operations Observable without Making Data Public: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## questions-objectives-narration

Display the entire mapping as a static table and emphasize the current row with text and a border.

Text alternative: Rows cover exact model identity, valid outcomes, failing slices, queueing, saturation, release change, cost, recovery, and incident scope.

## correlation-narration

Show the correlated rows simultaneously as a static table.

Text alternative: Gateway, adapter, server, runtime, policy, resource, and outcome rows share the run identifier and exact release identity without storing raw prompt content.

## correlation-demonstration

Present the diagnosis as a numbered static evidence table.

Text alternative: Metadata and exact identities support diagnosis and recovery while raw prompt and response content remain outside routine telemetry.

## telemetry-privacy-narration

Display the lifecycle as a static table with Required, Optional sensitive, Derived, and Prohibited labels.

Text alternative: Secrets and routine raw content are prohibited; bounded metadata and derived measures are preferred; approved samples receive strict controls.

## distributions-cost-narration

Provide exact histogram bucket counts and cost values in labeled static tables in addition to any charts.

Text alternative: Underlying histogram observations aggregate across replicas; precomputed p95 values are not averaged. Queue, first-output, processing, streaming, saturation, and cost are separate.

## alerts-investigation-narration

Use a static alert contract table with all response fields visible.

Text alternative: Alerts cover objective burn, queueing, identity mismatch, telemetry loss, and rollback failure, each with a named response and resolution condition.
