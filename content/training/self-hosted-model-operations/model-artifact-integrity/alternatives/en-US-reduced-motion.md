# Model Artifact Integrity and Safe Promotion: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## welcome-and-outcomes

Display all five zones simultaneously with numbered transitions and text labels for blocked paths.

Text alternative: Unreviewed files enter only bounded quarantine. Promotion to immutable trusted storage occurs only after required controls pass, and serving reads an approved immutable identity.

## quarantine-narration

Keep the zones and blocked paths static. Use text labels rather than animated transitions.

Text alternative: Acquisition occurs in a bounded non-serving quarantine without learner data or production credentials. Promotion remains blocked until all controls pass.

## quarantine-demonstration

Show the inventories as a static table and use text labels for each mismatch.

Text alternative: The candidate is blocked before loading because unexpected executable content and an unsafe link violate the approved inventory and path policy.

## evidence-narration

Keep the complete matrix visible and use a persistent row heading for the current topic.

Text alternative: Digests, signatures, provenance, scans, and inventories provide different limited evidence. None independently proves safe model behavior.

## executable-surfaces-narration

Present the sandbox and checks as a static numbered checklist.

Text alternative: Any unavoidable parser runs without production data or credentials and with strict resource, time, filesystem, privilege, and network limits.

## transformation-narration

Show input, transformation, output, and repeated gates as four static panels.

Text alternative: The transformed artifact has a new identity. Its UNKNOWN digest prevents promotion, and all required gates must be repeated.

## promotion-narration

Present promotion and revocation as two static ordered checklists with pass, hold, and reject states.

Text alternative: Promotion requires every evidence gate. Revocation blocks serving, preserves evidence, removes controlled copies, restores the last verified identity, and confirms recovery.

## worked-example-and-variation-lab-narration

Show the repair, inventory, and output in fixed panels without animated code or live execution.

Text alternative: The learner changes only the final inventory-binding expression. Full paths, commands, hashes, and expected output remain selectable text.

## negative-controls-demonstration

Display result lines statically with text labels for pass and reject. Do not animate a test runner.

Text alternative: The local verifier accepts the baseline and updated trusted variation and rejects tampering, unsafe paths, malformed evidence, unlisted files, duplicate entries, and software bill of materials mismatch.

## ecosystem-transfer-lab-narration

Show the comparison table and checklist as static content without animated provider logos.

Text alternative: Different model ecosystems require independent verification of artifact bytes, runtime compatibility, API contract, licensing, and custom-code policy.

## class-closing

Display the final rule as a static text card.

Text alternative: Inspect before execution. Match each claim to appropriate evidence. Promote only immutable artifacts with a tested revocation path.
