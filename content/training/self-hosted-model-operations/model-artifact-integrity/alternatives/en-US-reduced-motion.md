# Move Model Artifacts from Quarantine to Trusted Service: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## quarantine-narration

Display all five zones simultaneously with numbered allowed transitions and a text label for every blocked path.

Text alternative: Unreviewed files enter only quarantine. Promotion to a read-only trusted store occurs after every required gate passes; serving reads only immutable approved identities.

## quarantine-demonstration

Show both inventories in a static table and label mismatches with text and icons rather than motion or color alone.

Text alternative: The candidate is held before loading because unexpected executable content and an extraction escape violate the approved manifest.

## evidence-narration

Keep the full evidence matrix visible and mark the discussed row with a persistent heading.

Text alternative: Digests, signatures, provenance, scans, and inventories each provide limited evidence and none independently proves safe model behavior.

## executable-surfaces-narration

Present the sandbox and checks as a static numbered checklist with no animated execution.

Text alternative: Every unavoidable parser runs without production data or credentials and with strict resource, time, filesystem, privilege, and network limits.

## transformation-narration

Show input, transformation, output, and repeated gates as four numbered static panels.

Text alternative: The quantized output has a new identity and must repeat license, integrity, compatibility, and evaluation gates.

## promotion-narration

Present promotion and revocation as two static ordered checklists with explicit pass, hold, and fail states.

Text alternative: Promotion requires every evidence gate. Revocation blocks serving, preserves evidence, removes controlled copies, restores the last verified identity, and confirms recovery.
