# Respond to the Impact, Diagnose the Boundary, Prove the Recovery: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## detect-declare-narration

Display the declaration as a static table and emphasize the current field with text and a border.

Text alternative: Quality, access, cost, queue, artifact, telemetry, deployment, and user-report signals map to actual and credible impacts rather than assumed root causes.

## incident-demonstration

Present confirmed facts and hypotheses in two static columns.

Text alternative: Severity reflects credible authorization and duplicate-action impact; named roles and the first update are recorded before diagnosis.

## contain-preserve-narration

Show containment and evidence records as static labeled tables.

Text alternative: Routes, tools, identities, secrets, artifacts, rollouts, capacity, nodes, and sites can be contained independently; raw sensitive content is not collected by default.

## diagnose-boundary-narration

Display the complete diagnostic matrix as a static table.

Text alternative: Evidence distinguishes the first failure from downstream symptoms and requires system-of-record reconciliation for unknown outcomes.

## recover-validate-narration

Present recovery choices and postconditions as numbered static tables.

Text alternative: Health is one check among exact identity, authorization, quality, compatibility, queues, state, telemetry, cost, external effects, and user-visible recovery.

## communicate-learn-narration

Display the update, checklist, timeline, and backlog as static text tables.

Text alternative: Closure requires stopped impact, validated recovery, required communication, temporary-access cleanup, and dated owners for prevention work.
