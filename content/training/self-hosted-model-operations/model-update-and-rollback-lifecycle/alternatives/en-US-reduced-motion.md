# Release and Reverse the Complete Serving Unit: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## change-unit-narration

Display the complete manifest as a static table and emphasize the current dependency with text and a border.

Text alternative: Baseline and candidate columns show exact versions, digests, provenance status, intentional differences, detected drift, and retained recovery locations.

## manifest-demonstration

Present the difference and impact mappings in a static table.

Text alternative: The worked example exposes a streaming incompatibility, memory increase, and telemetry-contract drift that a model tag alone would hide.

## qualify-candidate-narration

Display the gate results as a static table with Pass, Hold, Reject, or Needs evidence labels.

Text alternative: Each gate compares baseline and candidate by case and slice and names hard failures, uncertainty, reviewer roles, and waiver authority.

## stage-release-narration

Show rollout strategies in a static comparison table instead of animated traffic movement.

Text alternative: Each environment has a controlled strategy; no candidate receives traffic before exact identity, warm-up, telemetry, and rollback checks pass.

## rollback-release-narration

Present rollback as numbered states and a static postcondition checklist.

Text alternative: A model alias change alone fails the test; exact identity, behavior, authorization, queues, telemetry, cost, and recovery must all be verified.

## evidence-improvement-narration

Use a static evidence table and numbered feedback list.

Text alternative: Approved and rejected candidates remain distinguishable; findings update evaluation, compatibility, capacity, migration, and recovery evidence.
