# Evaluate What You Will Actually Deploy: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## claims-and-gates-narration

Display the complete register as a static table and emphasize the current row with text and a border.

Text alternative: Every release claim is attached to the immutable artifact, tokenizer, template, adapter, runtime, quantization, hardware, policy, and configuration under test.

## claim-traceability-demonstration

Present the mappings simultaneously in a static table.

Text alternative: Grounding, language quality, authorization, latency, and rollback each have distinct cases, graders, thresholds, and evidence.

## versioned-cases-narration

Display the manifest and matrix as static labeled tables.

Text alternative: Representative, boundary, adversarial, accessibility, failure, incident, and holdout rows each list permission, sensitivity, rubric, expiry, and owner.

## graders-narration

Use a static assignment table and numbered escalation rules.

Text alternative: No grader has unlimited authority. Critical deterministic failures remain blocking, and model-assisted disagreement is preserved for review.

## slice-comparison-narration

Provide labeled numeric tables in addition to any distribution charts.

Text alternative: Averages sit beside slice pass rates, severity, uncertainty, disagreement, latency percentiles, resource use, and critical failures.

## release-disposition-narration

Present the disposition as a static form with all required fields visible.

Text alternative: The decision includes critical findings, exceptions, monitoring, expiry, stop conditions, human reviewers, and preserved rollback.
