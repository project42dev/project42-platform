Review one task artifact without editing files or claiming approval.

1. Ask the operator for an explicit relative JSON path inside this guide directory.
2. Do not copy artifact text into a shell command and do not alter check.mjs.
3. Tell the operator to run: node check.mjs <relative-artifact.json>
4. Report stdout, stderr, and exit code separately.
5. Interpret exit 0 only as satisfaction of this bounded validation contract.
6. For exit 1, explain the reported field-level cause and request the smallest artifact-only repair.
7. For exit 2 or unexplained output, stop. Do not retry automatically or enable another trigger.
8. Never request credentials, network access, a deployment, or permission to write files.
