# Coding and Analysis Workflow: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## bounded-work-order-explanation

Display all eight fields simultaneously with numbered labels and no animated form completion.

Text alternative: The work order names the outcome, inspected inputs, constraints, invariants, executable checks, isolated workspace, separately authorized actions, and rollback path.

## work-order-demonstration

Present the question, inspected inputs, invariants, checks, exclusions, and rollback as one static comparison.

Text alternative: The work order preserves source order count and value, inspects key grain, uses approved sample data, prohibits production writes, and defines reconciliation and rollback.

## small-increments-explanation

Show both complete lanes as numbered static steps without animated execution.

Text alternative: Both lanes inspect inputs, make one bounded change, review the diff or query, run a local check, and either continue or recover.

## direct-verification-explanation

Display the complete matrix with written Pass, Gap, and Not applicable values.

Text alternative: Code criteria map to tests, builds, failure paths, and observed behavior. Analysis criteria map to type, key, join, missingness, unit, and reconciliation checks.

## failure-recovery-explanation

Present the seven recovery fields as a numbered static sequence.

Text alternative: The record contains reproduction, evidence, layer classification, smallest repair, repeated check, regression check, and rollback or escalation decision.

## security-privacy-impact-explanation

Show every gate simultaneously with written Pass, Stop, or Escalate states and no animated completion.

Text alternative: The gate covers security, privacy, data validity, authorization, direct evidence, accountable review, deployment boundary, and tested rollback.
