# Context and Evidence Construction: reduced-motion presentation

Present every visual as a complete static composition. Do not make completion
depend on animation timing, autoplay, or pointer gestures.

## selected-context-explanation

Display the collection, criteria, and final set simultaneously. Use numbered text labels instead of animated filtering.

Text alternative: Documents pass through five explicit selection criteria. The final set contains only sources that can support the defined decision, while exclusions and gaps remain visible.

## context-pruning-demonstration

Show the complete disposition table with text labels. Do not animate sources moving between groups.

Text alternative: Current official documentation and policy are included, pricing is excluded, an old slide is recorded as a conflict, and a forum post is only a research lead.

## source-qualification-explanation

Show the entire evidence record as a static form and identify the current field with a persistent heading.

Text alternative: Each source has publisher, date, location, supported claims, scope limits, permission status, and a rule for conflicts.

## trust-boundary-explanation

Present all boundaries at once with solid labeled borders. Avoid moving text between containers.

Text alternative: Documents and user text can provide evidence but cannot change permissions, tool policy, secrets access, or the task's authorized instructions.

## grounding-limits-explanation

Display the complete ledger as a static table and use written support-status values instead of color alone.

Text alternative: Every claim maps to a source passage and support status. Inference and conflict are separate fields, and unsupported claims remain visible gaps.

## evidence-gap-demonstration

Show the full ledger and conclusion simultaneously. Use text support labels rather than animated check marks.

Text alternative: Feature documentation proves the feature exists, and a regional table proves three regions. Neither proves worldwide availability, so the global claim is recorded as an evidence gap.
