## Rules

1. Public APIs, schemas, and content IDs are versioned contracts.
2. Generated files under `src/generated/` are never hand-edited.
3. Content claims require primary sources and a verification date.
4. Core concepts remain provider-neutral.
5. No credentials, learner data, private PMO material, or hosted-site secrets.
6. Software uses Apache-2.0; `content/` uses CC BY 4.0 unless noted.
